# 设备故障规则检测：自定义 SCRIPT Skill 测试包

此目录用于测试“用户脚本 → 自定义 Skill → 自定义 Agent 权限 → 标准 Artifact”的完整链路。
它仅采用少量关键词规则，不应作为生产故障诊断能力。

## 创建 Skill

在正式端 `http://127.0.0.1:8000/workbench` 或测试端 `http://127.0.0.1:8002/` 点击“自定义能力 → 新增自定义 Skill”，填写：

| 字段 | 测试值 |
|---|---|
| 能力名称 | 设备故障规则检测 |
| 它要解决什么问题 | 从已解析的设备维修资料中识别故障、异常、报警、过热、振动、漏油、停机和失效信息，并给出风险等级。 |
| 适用什么资料 | 设备手册、维修记录、巡检报告和故障报告。 |
| 希望得到什么结果 | 输出风险等级、故障描述、处理建议和证据位置。 |
| 典型用户提问 | 请根据上传的设备维修资料识别故障风险项。 |
| 补充要求 | 这是规则测试能力，只依据文档原文命中词，不构建或发布图谱。 |

在“可选脚本或捆绑资源”中上传同目录的 `main.py`。提交后确认发布；平台会自动识别 `.py` 并将该 Skill 固定为 `SCRIPT` 执行方式。

## 授权给设备故障分析 Agent

进入“自定义能力 → 管理已创建的能力 → Agent 管理”，找到 **设备故障分析 Agent**：

1. 点击“编辑”；
2. 在“允许调用的 Skill”中勾选 **设备故障规则检测**；
3. 点击“保存为草稿”；
4. 回到管理列表点击“发布”。

测试期间，如该 Agent 同时有多个相似的故障分析 Skill，为了确认脚本必定被调用，可以暂时只保留本测试 Skill 的授权；测试结束后再恢复原授权。

## 测试用例

上传一个 DOCX 或 PDF，其正文至少包含：

```text
3号空压机运行时出现持续振动和高温报警。巡检人员发现轴承温度超过 95℃，
设备已停机等待检修。
```

用户提问：

```text
请使用设备故障规则检测，根据上传资料识别设备故障风险项，不要构建或发布图谱。
```

预期结果：

1. 总控不会创建构图、审核或发布子任务；
2. `设备故障分析 Agent` 认领故障分析子任务；
3. 该 Agent 调用 `设备故障规则检测`；
4. 运行记录显示 `SCRIPT`，并产生一个 `StructuredDataset`；
5. 结果至少有一行，包含“风险等级、故障描述、处理建议、证据位置”；其中风险等级应为“严重”。

如果出现 `SCRIPT_EXIT_ERROR`，检查脚本是否以 `main.py` 名称上传，以及脚本标准输出是否只有一个 JSON 对象；不要在脚本中打印调试日志。
